# FPGA Lab

The FPGA Lab is a high speed successor to the [atmega 32u4 based
chiplab board](../base_32u).

This board includes a 32u4 for ease of programming, as well as an [ice40
FPGA](https://www.mouser.com/ProductDetail/Lattice/ICE40UP5K-SG48I?qs=Rp3RbKSfAt3UqOG1AN4%2FAg%3D%3D)
for high speed interactions with the target chip-under-test.

For more about the chiplab, see articles [on the
site](https://emulationonline.com/systems/chiplab/).
